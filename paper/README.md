# Paper: build notes

Technical report "Lightsmith: an open, GPU-native, differentiable photonics suite for humans and
AI agents" (the package is still imported as `omniscatter` until the rename lands). arXiv metadata
and the upload checklist are in `ARXIV.md`.

`main.tex` is an arXiv-ready skeleton (plain `article`, natbib + `unsrtnat`, pdfLaTeX, no
custom packages). Red `[TODO: ...]` marks come from the `\todo{}` macro; remove the macro's
definition at submission to make any leftover a compile error.

## Build

```bash
cd paper
latexmk -pdf main.tex          # or: pdflatex main && bibtex main && pdflatex main && pdflatex main
```

No TeX distribution is installed on the development machine, so the skeleton has not been
compiled yet. Overleaf also works: upload `main.tex`, `references.bib` and `figures/`.

For arXiv, upload `main.tex`, `main.bbl` (generated by bibtex), and `figures/*.pdf`.

## Bibliography

`references.bib` is **generated**, not hand-written:

```bash
uv run --no-sync python paper/tools/make_bib.py
```

`tools/make_bib.py` fetches every entry from doi.org (CSL-JSON content negotiation) or the arXiv
API and checks the first author's surname and year against what we expect. Anything that does
not resolve or does not match is written commented out with the reason. The log of the last run
is `tools/bib_verification.json` (77/77 verified on 2026-11-01). To add a reference, add a line to
`ENTRIES` (or `URLS` for web resources) and re-run; do not type bibliographic fields by hand.

References mentioned in the code but not yet in the bib (add to `ENTRIES` and verify):
Piller (weighted DDA discretisation; the code's citation could not be matched yet); Taflove &
Hagness (book, no DOI); Granet & Guizal and Lalanne & Morris (RCWA factorisation); open TMM/RCWA/
mode/FDFD/PWE/circuit codes for Related work.

## Figures

`figures/*.pdf` are placeholders copied from the smoke run by

```bash
uv run --no-sync --with matplotlib python benchmarks/plots.py benchmarks/results/<dir> --paper
```

`figures/SOURCE.txt` records which results directory they came from. Re-run against the full
suite results before submission.
